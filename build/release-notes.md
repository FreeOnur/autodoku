## AutoDoku 3.3 – alles aus einer .exe

**⬇ [AutoDoku-Setup.exe herunterladen](https://github.com/FreeOnur/autodoku/releases/latest/download/AutoDoku-Setup.exe)** · Windows 10/11

### Neu
- 🧰 **Einrichtungs-Assistent:** Beim ersten Start KI wählen – AutoDoku lädt alles Nötige selbst (Fortschritt unten rechts).
- 🎙️ **Spracherkennung lokal mit Whisper large-v3-turbo** (whisper.cpp): deutlich genauer, startet nur beim Aufnehmen, beendet sich nach 10 Minuten Pause.
- 🦙 **Ollama wahlweise, von der App verwaltet:** Installation ohne Windows-Autostart (nur ≈ 40 MB statt 1,6 GB), Start bei Bedarf, beim Schließen von AutoDoku wird Ollama beendet und das Modell entladen.
- 🟠 **Claude** als Option für die beste Mitschrift-Qualität (eigener API-Schlüssel).
- ⚙️ **Leistung einstellbar** (Leise / Ausgewogen / Schnell) für Spracherkennung und Ollama.
- ⬆️ **Updates direkt in der App** (⚙️ → Über AutoDoku).

### Hinweise
- Windows-SmartScreen: *Weitere Informationen → Trotzdem ausführen* (noch kein kostenpflichtiges Zertifikat).
- Notizen, Einstellungen und Downloads bleiben bei Updates erhalten (`%APPDATA%\AutoDoku`).
